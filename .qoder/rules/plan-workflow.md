# Plan 文件规范

## 存放位置
- 所有 plan / 方案 / 设计文档一律写在 `.qoder/.plans/` 下，禁止写到项目根目录、`docs/` 或其他位置
- 每个需求单独建一个文件夹：`.qoder/.plans/<YYYYMMDD>-<需求短名>/`
- 需求短名用中文或短横线英文，能一眼看出是什么需求，例如：
  - `.qoder/.plans/20260830-项目初始化开发方案/`
  - `.qoder/.plans/20260901-骨骼平滑优化/`

## 文件组织
- 主方案文件固定名 `DEVELOPMENT_PLAN.md`
- 需求内的拆解、调研、验证记录放同一文件夹内，按用途命名（如 `RESEARCH.md`、`VERIFY.md`）
- 不同需求的文件不许混在一个文件夹里；需求有后续迭代时，在原文件夹内追加文件或更新原文件，不新建重复文件夹

## 内容要求
- 开头写「最后更新日期 + 当前 Commit」，每次改动同步更新
- 只写可操作内容：改哪些文件、做什么、怎么验证；不写背景铺垫和原理解释
- 进度用 `- [ ]` / `- [x]` 勾选表示，完成后立刻回写状态
